Пользовательский интерфейс состоит из 3D-окна (Viewport), основной панели инструментов (Main Toolbar), дерева объектов (Objects Tree), панели свойств (Properties pannel) и окно журналов (Logs and Traceback).

![](media/d526d306b7f5d2261461c1878bc0d738.png)

Основная панель инструментов включает всё, что необходимо для сборки модели симуляции: детали, системы координат, пружины и силы, движения и элементы управления симуляцией. Объекты, созданные в модели симуляции, сразу появляются в дереве объектов. Выбранный объект двойным кликом отображается в панели свойств для просмотра и изменений.

3D-экран включает следующие кнопки управления:

![](media/9030c98f47f0b29e798a757489226cd3.png) Отобразить / скрыть края 3D-детали,

![](media/94360b61f30640d4ef97059ae9c0ed4c.png) Отображение / скрытие координатной сетки,

![](media/a3f29d2985baefbbe4222caf4ce7f892.png) Скрыть все объекты, кроме выбранного объекта,

![](media/cdad5bd378be17f2af59443319fca9ca.png) Показать все объекты в 3D-окне,

![](media/6cd50156ff0fa9109ac1bcdad1856ba6.png) Переключить яркий/тёмный фон в 3D-окне,

![](media/298ecba7ba9c87f8a277b748220404ba.png) Снять выделение со всех объектов,

![](media/bb021f5bf9cbacbadf61a51f4447f75b.png) Скрыть визуализацию для систем отсчёта, соединений, сил и крутящих моментов,

![](media/f6ff32bde692afe9f02da119a2e8a9b5.png) Зафиксировать фактический размер визуальных элементов для систем отсчета, соединений, сил и крутящих моментов

![](media/de5463fe383e239668ad3126a99a9efb.png) Переключить 3D-просмотр между перспективной и ортографической (параллельной) проекцией,

![](media/630ebbaad1238b5bbae68fc81c032d4e.png) Поместить все объекты в 3D-окне,

![](media/fa9519153e351dfc8326e8de8dea1c2c.png) Показать сцену в плоскости XY,

![](media/f828a60f479e5fa040efcaac13a86bc4.png) Показать сцену в плоскости ZY,

![](media/cfb19c6d5cdd5b10cffff0415aa054de.png) Показать сцену в плоскости XZ.
