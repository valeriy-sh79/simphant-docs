Інтерфейс користувача складається з 3D-вікна (Viewport), основної панелі інструментів (Main Toolbar), дерева об'єктів (Objects Tree), панелі властивостей (Properties pannel) та вікно журналів (Logs and Traceback).

![](media/d526d306b7f5d2261461c1878bc0d738.png)

Основна панель інструментів містить усе, що потрібно для складання моделі симуляції: деталі, системи координат, пружини та сили, рухи та елементи керування симуляцією. Об'єкти, створені в моделі симуляції, одразу з'являються в дереві об'єктів. Вибраний об'єкт подвійним натисканням відображається на панелі властивостей для перегляду та змін.

3D-екран містить такі кнопки керування:

![](media/94360b61f30640d4ef97059ae9c0ed4c.png) Відображення/приховування координатної сітки,

![](media/a3f29d2985baefbbe4222caf4ce7f892.png) Приховати всі об'єкти, крім вибраного об'єкта,

![](media/cdad5bd378be17f2af59443319fca9ca.png) Показати всі об'єкти у 3D-вікні,

![](media/6cd50156ff0fa9109ac1bcdad1856ba6.png) Перемкнути світлий/темний фон у 3D-вікні,

![](media/298ecba7ba9c87f8a277b748220404ba.png) Скасувати виділення всіх об'єктів,

![](media/bb021f5bf9cbacbadf61a51f4447f75b.png) Приховати візуалізацію для систем відліку, з'єднань, сил і крутних моментів,

![](media/f6ff32bde692afe9f02da119a2e8a9b5.png) Зафіксувати фактичний розмір візуальних елементів для систем відліку, з'єднань, сил і крутних моментів
