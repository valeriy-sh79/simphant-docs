The User Interface consists of the 3D Viewport, the main Toolbar, objects Tree hierarchy, the Property panel, and traceback window.

![](media/d526d306b7f5d2261461c1878bc0d738.png)

The main Toolbar includes all required to assembly the simulation model: the Bodies, Reference Frames, Springs and Forces, Motions and the Simulation controls. The objects created in the simulation model immediately appear in the Objects Tree. Being selected by double-click the object properties are displayed in the Property panel for review and modifications.

The 3D Viewport includes following control buttons:

![](media/9030c98f47f0b29e798a757489226cd3.png) Display / hide 3D Body edges,

![](media/94360b61f30640d4ef97059ae9c0ed4c.png) Display / hide Grid,

![](media/a3f29d2985baefbbe4222caf4ce7f892.png) Hide all objects except selected Body,

![](media/cdad5bd378be17f2af59443319fca9ca.png) Unhide All objects in the Viewport,

![](media/6cd50156ff0fa9109ac1bcdad1856ba6.png) Toggle bright / dark background in the Viewport,

![](media/298ecba7ba9c87f8a277b748220404ba.png) Unselect All objects,

![](media/bb021f5bf9cbacbadf61a51f4447f75b.png) Hide visuals for Reference Frames, Joints, Forces and Torques,

![](media/f6ff32bde692afe9f02da119a2e8a9b5.png) Freeze the actual size of the visuals for Reference Frames, Joints, Forces and Torques

![](media/de5463fe383e239668ad3126a99a9efb.png) Toggle the 3D Viewport between Perspective and Orthographic (Parallel) projection,

![](media/630ebbaad1238b5bbae68fc81c032d4e.png) Fit All object in the current view,

![](media/fa9519153e351dfc8326e8de8dea1c2c.png) Orient current view in XY-plane,

![](media/f828a60f479e5fa040efcaac13a86bc4.png) Orient current view in ZY-plane,

![](media/cfb19c6d5cdd5b10cffff0415aa054de.png) Orient current view in XZ-plane.
